HOW TO USE
GETTING STARTED
Click anywhere on the title screen to begin. In the 3D view, drag to rotate the camera and scroll to zoom. The scene auto-rotates slowly on its own.
CHOOSING A SYSTEM
Use the dropdown (top-left) to pick from 9 real chaotic systems -- Lorenz, Rössler, Thomas, Halvorsen, Aizawa, Chen, Chua's Circuit, Four-Wing, and Sprott B -- or select Custom to write your own.
PARAMETERS
The sliders below the equations are that system's actual constants. Drag one and watch the attractor reshape live -- nothing is precomputed, it's solving the equations every frame.
THE SENSITIVITY DEMO
The cyan and magenta clouds start almost exactly on top of each other -- how close is set by the ε (epsilon) slider. Watch how quickly they separate. The chart plots that separation on a log scale over time: a rising straight line is exponential divergence, the signature of chaos. The number below it is a live estimate of the system's Lyapunov exponent -- most meaningful while the line is still climbing, before it saturates.
CUSTOM EQUATIONS
Selecting Custom swaps the equation display for three text fields. Type your own dx/dt, dy/dt, dz/dt using x, y, z and parameters p1, p2, p3 (adjustable via the sliders). Functions like sqrt, sin, cos, tan, log, ln, exp, abs all work. Invalid syntax just keeps the last working version running -- it won't crash anything.
PLAYBACK
Pause freezes the simulation (camera still moves freely). Step advances exactly one frame while paused -- useful for explaining a single moment. Speed slows down or speeds up time itself. Reset All rescatters everything from scratch.
THE LOGISTIC MAP
A completely different, simpler kind of chaos: one line, x next = r·x·(1−x), repeated. Drag r and watch the bifurcation diagram's marker move -- past r ≈ 3.57 it turns chaotic. Try r ≈ 3.83 for a "window" of perfect order hiding inside the chaos. The cobweb plot on the right shows exactly how each value is generated from the last.
WHO THIS IS FOR
Self-guided exploration: the "How to Use" panel is written so a student can drive the tool without supervision -- it directly points at the epsilon slider and the diverging clouds as the way to discover sensitive dependence firsthand, and the Custom system is a safe sandbox for typing dx/dt, dy/dt, dz/dt by hand with no way to permanently break anything.
University-level dynamical systems & ODE instruction: separation is plotted on a log scale over time, and a live Lyapunov exponent estimate (a rolling 150-frame least-squares slope) turns "this looks chaotic" into an actual measured number. The 9 built-in systems let an instructor demonstrate a real bifurcation directly -- lowering Lorenz's ρ below ≈24.7 visibly collapses chaos into two stable fixed points. Worth reading the source itself, too: eqBuildEvaluator() is a from-scratch recursive-descent parser with no eval, and integrate() uses 4th-order Runge-Kutta specifically because plain Euler integration was measured to produce wrong qualitative behavior near that same bifurcation.
High school / population ecology: the Logistic Map view isolates one discrete rule with no calculus required, and the cobweb plot makes "this frame's output becomes next frame's input" visible rather than abstract. One clarification: it's not exclusively an introductory tool -- the same view demonstrates the identical bifurcation concept as the university-level point above (a single parameter crossing a threshold), just with simpler prerequisites. It's a shared concept shown at two depths, not two different concepts.
No backend required: every computation -- RK4 integration, expression parsing, rendering -- runs entirely in the browser, and in this file specifically, Three.js, Tailwind, and the fonts are bundled in rather than loaded from a CDN, so it also needs no network access at all, even on first open.
